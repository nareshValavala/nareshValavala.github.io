The mechanism

Diff two phoneme strings, not one vague opinion

Expected phonemes come from the prompt text. Produced phonemes come from the audio. Align, diff, and every flagged issue lands on a position in a word.

A multimodal model asked "how did that sound" returns fluent prose you can't verify and can't locate. This is inspectable when it's wrong.

Decisions Chosen / rejected

Built as a personal tool, not a product. Privacy and cost win whenever they conflict with polish.

Everything local

No cloud APIs, no accounts, nothing leaves the machine. Costs a 1.2GB first-run download.

Rejected: cloud speech APIs. Per-minute billing kills daily practice.
Phoneme diffing

Every issue traceable to a position, and inspectable when the scorer is wrong.

Rejected: a model describing the audio. Unverifiable, can't locate anything.
LLM optional, and last

Ollama rephrases feedback if present. Templates are the guaranteed baseline.

Rejected: an LLM in the scoring path. Measurement isn't a wording problem.
Degrade, don't block

Piper missing falls back to browser speech. Rhubarb missing just freezes the mouth diagram.

Rejected: hard binary dependencies. A tool nobody can start is worse.
Subprocess, never import

Keeps third-party licenses independent of this repo's MIT. Piper's archived MIT release kept over the maintained GPL fork.

Rejected: the convenient import. It would pull copyleft into an MIT repo.
